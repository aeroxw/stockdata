Capabilities

不只是数据搬运

六家接口格式天差地别 —— GBK 的波浪号分隔串、JSON 里的 f43/f44 编码字段、REST 信封…… 全部收敛后再交付给你。

🔀
统一数据模型
所有数据源输出同一个 Quote / KlineBar 结构，字段命名与单位统一（成交量统一为股、成交额统一为元）。 切换数据源不改一行业务代码。
🛡️
主备自动切换
按优先级链式取数，某源超时或异常自动降级到下一源，接口层完全无感。 交易时段感知，非交易时段自动停采避免触发风控。
⚖️
多源交叉校验
同一标的多源比对价格，偏差超阈值即告警。数据质量是这类平台的生命线， 我们不把"拿到数据"当成"拿到正确的数据"。
🔑
API Key 自助管理
自助创建、命名、设权限范围与过期时间，支持一键轮换与即时吊销。 数据库只存哈希，明文密钥仅创建时展示一次。
⚡
分层缓存与限流
Redis 缓存盘中快照（3 秒）与 K 线（5 分钟），按 Key 滑动窗口限流， 超额返回 429 与 Retry-After，绝不静默丢请求。
📊
调用可观测
每次调用落库记录路径、状态码、耗时，后台提供按用户/按接口/按时间维度的统计大盘与用量查询。

Quick Start

三步接入，一次调用

注册 → 创建 API Key → 发起请求。响应是统一信封，业务数据永远在 data 里。

Python
import requests BASE = "http://<你的域名>:9850/api/v1" HEADERS = {"Authorization": "Bearer sk_live_xxx"} # 1) 实时行情 —— 支持一次多只 r = requests.get(f"{BASE}/quote", headers=HEADERS, params={"codes": "600519.SH,000001.SZ,300750.SZ"}) print(r.json()["data"]) # 2) 历史 K 线 —— 前复权日线 k = requests.get(f"{BASE}/kline", headers=HEADERS, params={"code": "600519.SH", "period": "day", "limit": 100, "adjust": "qfq"}) # 3) 特色数据 —— 涨停池 / 龙虎榜 s = requests.get(f"{BASE}/special/limit_up", headers=HEADERS)
JavaScript
const BASE = "http://<你的域名>:9850/api/v1"; const HEADERS = { "X-API-Key": "sk_live_xxx" }; // 实时行情 const res = await fetch( `${BASE}/quote?codes=600519.SH,000001.SH`, { headers: HEADERS } ); const { data, meta } = await res.json(); console.log(`数据来自: ${meta.source}`, data); // 龙虎榜（可指定开盘了源做交叉校验） const lhb = await fetch( `${BASE}/special/dragon_tiger?source=kaipanla`, { headers: HEADERS } );
cURL
# 行情快照（三种传 Key 方式任选其一） curl "http://<你的域名>:9850/api/v1/quote?codes=600519.SH" \ -H "Authorization: Bearer sk_live_xxx" curl "http://<你的域名>:9850/api/v1/quote?codes=600519.SH" \ -H "X-API-Key: sk_live_xxx" # 涨停池 curl "http://<你的域名>:9850/api/v1/special/limit_up" \ -H "Authorization: Bearer sk_live_xxx" # 前复权日线 curl "http://<你的域名>:9850/api/v1/kline?code=600519.SH&period=day&limit=100&adjust=qfq" \ -H "Authorization: Bearer sk_live_xxx"

Why StockData

和直接对接单一数据源的区别

自建采集最贵的地方从来不是写代码，而是长期的运维与容错。

能力 直连单一数据源 StockData 统一接入
接入成本 每家一套解析逻辑，GBK / 编码字段 / 信封各不相同 一套接口，六种协议差异已在适配层消化
服务可用性 单源故障即中断，需自己写降级 六源优先级链，超时自动切换下一源
数据正确性 无法自证，错了也不知道 多源交叉校验，偏差超阈值告警
缓存与限流 全部自建，否则容易被封 IP 内置分层缓存 + 按 Key 滑动窗口限流
密钥与配额 无 控制台自助创建/轮换/吊销，按档位配额
特色数据 分散在各家，字段口径不一 统一出口，龙虎榜双源可交叉比对
