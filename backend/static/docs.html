鉴权方式

所有 /api/v1/* 接口都需要在请求头携带 API Key：

三种传法任选其一，服务端都会识别：

HTTP Header / Query
Authorization: Bearer sk_live_xxxxxxxxxxxxxxxxxxxx X-API-Key: sk_live_xxxxxxxxxxxxxxxxxxxx ?apikey=sk_live_xxxxxxxxxxxxxxxxxxxx # 便于浏览器地址栏调试
💡 API Key 明文仅在创建时显示一次，请妥善保存。遗失后请在控制台轮换生成新密钥。

密钥生命周期

一个 API Key 有三种状态，对应三个操作。控制台的按钮会随状态切换：

POST /api/v1/apikey
创建。明文只在这一次响应里返回（字段 secret），之后只能看到掩码，请立刻保存。
DELETE /api/v1/apikey/{id}
吊销（软删除）：立即失效并写入 Redis 黑名单，调用方无需等缓存过期。记录保留，可追溯，仍占用配额位。
DELETE /api/v1/apikey/{id}/purge
永久删除（物理删除）：从数据库抹掉记录，不可恢复。只能删除已吊销的密钥，未吊销会返回 400。历史调用日志（api_logs）会保留，用于审计。
💡 建议流程：先吊销 → 观察 1～2 天确认没有程序在用 → 再永久删除。直接删未吊销的密钥是不允许的，就是为了避免误删正在服务的密钥。

免鉴权接口

以下两个接口不需要 API Key，用于主页展示与快速体验：

GET /api/v1/public/quote
返回固定演示标的的实时快照（上证指数、贵州茅台、五粮液、中国平安、招商银行、平安银行）。
GET /api/v1/public/market
市场概览：三大指数 + 科创50、全市场涨跌家数、涨停/跌停统计、领涨领跌榜。结果缓存 30 秒。
market 响应结构
{ "indices": [ {code, name, price, change, change_pct, ...} ], "breadth": { total, up, down, flat, limit_up, limit_down, avg_pct, median_pct, up_ratio }, "top_gainers": [ {code, name, price, change_pct} ], "top_losers": [ {code, name, price, change_pct} ] }

行情快照

GET /api/v1/quote?codes=600519.SH,000001.SZ
批量实时快照。多源自动选主，异常时自动降级。单次最多 200 只。
codes必填股票代码，逗号分隔。支持 600519 / sh600519 / 600519.SH 三种写法
source可选指定数据源：tencent / hithink / sina / eastmoney。不填则自动选择
响应字段
code, name, price, pre_close, open, high, low, volume（股）, amount（元）, change, change_pct, turnover_rate（换手率%）, vol_ratio（量比）, circ_mv（流通市值/亿）, pe, pb, ts

历史 K 线

GET /api/v1/kline?code=600519.SH&period=day&limit=100&adjust=qfq
默认走通达信（全市场批量最快），失败自动降级到同花顺 / 东财。
code必填单只标的代码
period可选day / week / month / 60min / 30min / 15min / 5min / 1min，默认 day
limit可选返回条数，1~2000，默认 100
adjust可选none / qfq（前复权，默认）/ hfq（后复权）
source可选tdx（默认）/ hithink / eastmoney

限流与错误码

按 API Key 做分钟级滑动窗口限流。超限返回 429 并带 Retry-After 头。

0成功—
400参数错误检查必填参数与取值范围
401未授权缺少 / 无效 / 已吊销 / 已过期的 API Key
403权限不足该 Key 未分配对应 scope
429频率超限降低频率后重试，参考 Retry-After
502数据源不可用所有数据源均失败，稍后重试
